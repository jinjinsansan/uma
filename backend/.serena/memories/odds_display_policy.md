# オッズ表示ポリシー（重要）

## 現在の仕様（2025-01-18実装）

### UIでの表示
- **オッズ列は非表示** - すべての出走表でオッズ列を削除済み
- 表示されるのは「予想勝率」と「予想複勝率」のみ
- 理由：レース時点でオッズが変動するため、古いオッズ表示は誤解を招く

### 内部データ
- **TSファイルにはオッズデータ必須** - AI分析に必要
- netkeiba.comからコピペ時は今まで通りオッズも取得する
- F-Logic、Meta-Logicの分析精度に直結

### 修正済みファイル
1. `/src/components/v2/race/RaceTable.tsx` - オッズ列削除
2. `/src/app/v2/chat/[sessionId]/page.tsx` - オッズ列削除

### 重要ポイント
- コンポーネントレベルで制御しているため、TSファイルにオッズがあっても画面には表示されない
- 新しいClaudeと作業する際も、通常通りオッズをTSファイルに保存してOK
- 内部的にオッズは必須（予想勝率・複勝率の計算、AI分析に使用）

### データフロー
```
netkeiba.com → TSファイル（オッズあり） → コンポーネント → 画面（オッズなし）
                     ↓
              AI分析で内部使用
              - 予想勝率 = 1/(オッズ+1)×100
              - 予想複勝率 = 勝率×2.5
```
