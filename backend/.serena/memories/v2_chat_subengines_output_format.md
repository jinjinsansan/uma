# V2チャット サブエンジン出力形式ドキュメント

## 1. 傾向分析サブエンジン（ViewLogicコース傾向分析）

### 概要
- **関数名**: `_format_trend_analysis` (services/v2/ai_handler.py:860-1044)
- **目的**: コース傾向を分析し、出場馬・騎手のコース適性を評価

### 出力形式

#### セクション構成
1. **タイトル**: 📊 **ViewLogicコース傾向分析**
2. **コース情報**: [会場]コース

#### 主要3項目

##### 【出場馬の当コース成績】
```markdown
**【出場馬の当コース成績】**
1. **馬名A**: 5戦 複勝率60.0%
2. **馬名B**: 3戦 複勝率33.3%
...
以上が当コースで出走経験のあるN頭です。
その他の馬（馬名X, 馬名Y他）は当コースでの出走経験がありません。
```

##### 【騎手の当コース成績】
```markdown
**【騎手の当コース成績】**
1. **騎手A**: 42戦 勝率19.0% 複勝率38.1%
2. **騎手B**: 28戦 勝率14.3% 複勝率32.1%
...
以上が当コースで騎乗経験のあるN名です。
その他の騎手は当コースでの騎乗経験がありません。
```

##### 【騎手の枠順別成績】
```markdown
**【騎手の枠順別成績】**
1. **騎手A**（3枠）: 8戦 複勝率37.5%
2. **騎手B**（5枠）: 12戦 複勝率41.7%
...
以上が出場騎手N名の枠順別成績です。
```

##### 【ポイント】
```markdown
**💡 ポイント**
• 分析ポイント1
• 分析ポイント2
```

### データ取得元
- MySQLデータベース（過去7年分のレースデータ）
- 統合ナレッジファイル（CDN経由）
- リアルタイム分析

## 2. 血統分析サブエンジン（種牡馬分析）

### 概要
- **関数名**: `_generate_sire_analysis` (services/v2/ai_handler.py:2807-2938)
- **目的**: 出走馬の血統（父・母・母父）と産駒成績を分析

### 出力形式

#### セクション構成
1. **タイトル**: **血統分析**
2. **レース情報**: 【[会場] [レース番号]R】

#### 各馬の情報

```markdown
【1番】 **馬名**
  ◆ 父　：父馬名
  ◆ 母　：母馬名
  ◆ 母父：母父馬名

    └ 父 [会場][距離]m成績: 15戦3勝 複勝率40.0%
      良: 10戦2勝 複勝率30.0%
      稍重: 3戦1勝 複勝率66.7%
      重: 2戦0勝 複勝率50.0%

    └ 母父 [会場][距離]m成績: 8戦1勝 複勝率37.5%
      良: 5戦1勝 複勝率40.0%
      稍重: 3戦0勝 複勝率33.3%
```

### 特徴
- JRA（中央競馬）のみ産駒成績を表示
- 地方競馬は血統情報のみ表示（産駒成績なし）
- 馬場状態別の詳細成績を含む
- 0戦のデータは表示しない

### データソース
1. **血統情報**: 統合ナレッジファイル（DLogicRawDataManager経由）
2. **産駒成績**: SirePerformanceAnalyzer（MySQLデータベース）
   - 父の産駒成績
   - 母父の産駒成績
   - 馬場状態別成績

---

## 実装上の注意点

### 傾向分析
- 複勝率の正規化処理（0-100%範囲に修正）
- データがない場合の適切なメッセージ表示
- 騎手枠順別成績の型チェック処理

### 血統分析  
- 地方競馬判定（`_is_local_racing`）
- 会場コードマッピング（JRA 10場）
- 産駒成績取得時のエラーハンドリング
- 0戦データの非表示処理

### 共通
- エラー時のフォールバック処理
- ログ出力による監視
- 型チェックによる堅牢性確保
